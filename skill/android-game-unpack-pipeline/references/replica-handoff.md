# 从清道夫解包到完整复刻的交接要求

本清单用于用户明确要求后续复刻的提取任务；只下载 SWF 时不强制导出全套工程或建空目录。普通 Android 资源提取按引擎完成适用项，不套用 Flash 专属要求。

## 必须完成的交接

1. **确认输入。** 记录 URL/本地来源、主游戏文件、哈希和依赖。根据入口、帧数、类、加载引用与实际画面识别广告、启动器、主 SWF、外置资源；不能只下载第一个 SWF 即宣称全部获取。
2. **保留证据。** 自动解包明确调用 FFDec，保留原始 SWF、AS、位图、Shape、MorphShape、音频、文本、类映射与 FLA/XFL。按当前工具支持情况记录缺失，不伪造未导出的时间轴。
3. **记录转换。** 为消费资源保留原文件/符号/帧 → 运行文件、尺寸、透明度、哈希、转换方式和结果。图像只含位图时说明尚未统计矢量与组合动画。
4. **校验可用性。** 检查格式签名、实际尺寸、可解码性、声音时长与实际播放；按不同转换路径检查透明渐变、文字、遮罩、滤镜与大倍数缩放。不能把文件扩展名正确当成内容正确。
5. **分开交付。** 原始证据、运行素材、中间文件、报告分开存放；只给 FE 接入实际使用的去重图片、声音和必要运行数据。不向 Assets 整包复制 AS、FLA、SVG、字体和历史整帧图集。
6. **交出失败清单。** 每项写明输入、执行步骤/工具、真实错误、受影响类别、可用结果与下一步。目录无权限、下载失败、模拟器兼容、加密、缺依赖、转换不支持不能混写成同一个“解包失败”。
7. **交接后续清单。** 指出可用于研究的入口、屏幕、模型、输入、教程、存档、商店及动画符号。未分析的逻辑明确标未分析，不能称玩法已完整移植。

## 三种结论不能互换

| 结论 | 必须有的证据 |
| --- | --- |
| 已获取主 SWF | 主文件身份、依赖与完整性验证 |
| 已完成所需资源导出 | 请求类别的导出/转换结果与失败账目、内容可用性检查 |
| 已完成完整 FE 复刻 | 原版行为矩阵、适用功能全实现、运行及实际视觉对照、生产构建和版本交付 |

如果受阻，只关闭证据已满足的阶段；其他阶段保持未完成。继续独立工作，不把所有未知交给用户逐项发现。

## 本次实际漏项需要预防

- 不只有 images：界面、角色、箭头、按钮、评级和开场可能来自 Shape/Sprite/MorphShape。
- 不只有静态图：父子时间轴、stop 帧、标签、滤镜、透明度、颜色与矩阵是复刻数据。
- 不只有点击主线：菜单、存档、三名角色、剧情/跳过、教程限制、退回/取消、重复交付、升级和跨日都要交给后续行为盘点。
- 资源“看起来黑色”可能是滤镜输入；矢量渐变渲染也可能产生错误黑底。先查源结构，不擅自重画。
- 接入资源后仍要验证位置和行为。此次餐盘偏右的根因是父子坐标，不是导出图片或星级排序；提取成功不能为这些实现问题背书。
